# AI usage

This project was built with Claude Code (Claude Opus 5.5) as the main coding
agent, and Claude is also the product's first user, through the MCP server.

## Workflow

1. **Research.** Claude read the fest's rules, prizes and kits pages, the
   QoreChain docs and the ~170 projects already entered, then the winner lists
   of Solana Cypherpunk, Solana Breakout and ETHGlobal events, and proposed
   adapting the x402/MCP payment winners (MCPay, Corbits, zkx402) to the
   Protocol Builders track, where no other team was building agent payments.
2. **API discovery.** Claude installed `@qorechain/rdk` in a scratch folder,
   read its type definitions, and ran a probe script to confirm behaviour
   before writing code: deposits, nonce rules, a bad-nonce transfer being a
   no-op, withdrawals, fraud-proof decisions and ML-KEM envelopes.
3. **Implementation.** Claude wrote the core, mock L1, live adapter,
   facilitator, operator, watchtower, provider, agent wallet, MCP server and
   dashboard.
4. **Verification.** Claude wrote `scripts/demo.ts` (14 end-to-end checks) and
   ran it. The first run failed 2 checks: the mock L1 reused batch positions
   after a rejection, so the honest re-batch was refused. Claude fixed it and
   re-ran until all checks passed, then drove the dashboard in a browser to
   confirm the attack and rejection show correctly.

Update the human column as the team works. Every AI-written change was run
through `npm run typecheck` and `npm run demo`.
